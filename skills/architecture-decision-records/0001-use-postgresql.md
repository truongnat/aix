# ADR 0001: Use PostgreSQL as Primary Database

- **Status:** Accepted
- **Date:** 2024-01-10

## Decision

Choose PostgreSQL as the primary relational database for transactional application data.

## Context

Record the problem, constraints, evidence, and alternatives considered before changing this decision.

## Consequences

Document operational, data, migration, and maintenance consequences in the project-specific ADR when this record is adopted.
