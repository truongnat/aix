# Research source, evidence and reproducibility register

| Field | Required evidence |
|---|---|
| Question/decision | Exact question, decision context, scope and freshness requirement |
| Source | Stable ID, title, publisher/author, URL/path, source type, publication/access date and version |
| Claim | Claim text, supporting source IDs, quote/location or extracted data, confidence |
| Method | Search terms, databases/sites, inclusion/exclusion rule and stopping rule |
| Synthesis | Finding, inference boundary, comparison matrix, recommendation and why-not alternatives |
| Caveat | Conflicting/stale/missing evidence, impact and mitigation |
| Reproduction | Snapshot/export, query/date, transformation steps, code/version and environment notes |
| Handoff | Artifact path, reviewer focus, next owner and required follow-up |

Worked scenario: if two official sources disagree, keep both source IDs, identify version/date scope, state the conflict, and lower confidence or ask a blocking question. Never resolve citation conflict by silently choosing the convenient source.
